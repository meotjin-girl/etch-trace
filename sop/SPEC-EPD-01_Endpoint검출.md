# SPEC-EPD-01 Endpoint 검출 기준

| 항목 | 내용 |
|---|---|
| 문서 ID | SPEC-EPD-01 |
| 개정 | Rev 0.1 (예시, 2026-10-20) |
| 문서 유형 | 판정 기준서(SPEC) |
| 적용 장비 | OES(광방출 분광) endpoint 검출기가 있는 플라즈마 식각 챔버 |
| 관련 문서 | SOP-ETCH-12, WI-PM-07 |

> `[예시]` 수치는 시연용이다.

## 1. 목적

endpoint 검출(EPD) 설정을 어떻게 관리하고, endpoint가 늦거나 안 잡힐 때 무엇을 어떤 순서로 보는지 정한다.

## 2. 적용 범위

endpoint로 식각 종료를 판정하는 모든 recipe step. 시간 고정 step은 제외한다.

## 3. 용어

| 용어 | 뜻 |
|---|---|
| endpoint 시간 | step 시작부터 EPD가 종료를 판정한 시각까지 |
| window | 챔버 안 플라즈마 빛을 분광기로 보내는 창 |
| gain | 검출 신호 증폭 설정 |
| 최소/최대 시간 | 이 시간 전에는 판정하지 않고, 이 시간이 지나면 강제 종료(timeout)한다 |

## 4. 설정 관리

recipe마다 감시 파장, gain, 판정 threshold, 최소·최대 시간을 정하고 변경 이력을 남긴다. 설정 변경은 engineer 승인 후에만 한다.

## 5. 정상 판정

- endpoint 시간이 기준 run 중앙값 대비 5% `[예시]` 이내
- 판정 시점의 신호 변화 폭(기울기)이 기준 run과 비슷함
- timeout 없음

기준 run은 SOP-ETCH-12 §4.3으로 고른다.

## 6. 이상 대응

### 6.1 Endpoint 미검출 (timeout)

1. 해당 웨이퍼를 hold하고 잔막·과식각을 계측한다.
2. 챔버를 hold하고 SOP-ETCH-12 §4.1을 시작한다.

### 6.2 Endpoint 신호 지연

Endpoint 신호 지연 시 window 오염, gain 설정, 광원 상태를 순차 점검한다.

1. **window 오염:** 신호의 절대 세기를 마지막 PM 직후 run과 비교한다. 지연과 함께 세기가 꾸준히 줄었다면 창 안쪽 면에 폴리머·반응 부산물이 쌓여 빛을 흡수·산란하고 있을 가능성이 크다. 마지막 window 세정 이후 RF 누적 시간을 함께 적는다.
2. **gain 설정:** recipe의 gain·threshold가 표준값과 같은지, 최근 변경 이력이 있는지 확인한다.
3. **광원·검출기:** 기준 광원으로 분광기·광섬유 상태를 확인한다.

단, SOP-ETCH-12 §4.2에 따라 endpoint 지연이 10% 이상이면 RF·압력·가스 이력을 먼저 함께 비교한다. 실제 식각이 느려져서 endpoint가 늦게 잡힌 것이면 EPD 점검으로는 해결되지 않는다.

### 6.3 Window 세정·교체 후 확인

1. WI-PM-07 §3.1에 따라 세정 전후 신호 세기를 기록한다.
2. 세정 후 seasoning이 끝난 run에서 endpoint 시간과 신호 세기가 정상 범위로 돌아왔는지 확인한다.

## 7. 기록

- 이상 run ID, endpoint 시간(sec)과 기준 대비 지연률, 신호 세기
- 점검 단계별 결과, 설정 변경 여부, window 세정·교체 여부
