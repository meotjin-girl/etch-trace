# WI-MFC-02 MFC 점검 및 진공 누설 확인

| 항목 | 내용 |
|---|---|
| 문서 ID | WI-MFC-02 |
| 개정 | Rev 0.1 (예시, 2026-10-20) |
| 문서 유형 | 작업 지시서(WI) |
| 적용 장비 | 식각 장비 공정 가스 MFC, 챔버 진공 계통 |
| 관련 문서 | SOP-ETCH-12, SOP-SAFE-01, WI-PM-07 |

> `[예시]` 수치는 시연용이다. MFC 교정 기준은 업체 매뉴얼과 사내 교정 표준을 따른다.

## 1. 목적

가스 유량(MFC)과 챔버 진공 누설을 확인해, 압력 불안정과 etch rate 저하가 가스 공급 문제인지 가린다.

## 2. 적용 범위

공정 가스 MFC (예: CF4, CHF3, O2, Ar), 챔버 rate-of-rise leak check.

## 3. 역할

- engineer: 점검 결정, 결과 판정, 교정·교체 승인
- 설비 담당 engineer: 점검 수행

## 4. 사전 조건

1. 장비 상태가 Unscheduled 또는 Scheduled downtime이다.
2. 독성·가연성 가스 MFC를 분리할 때는 SOP-SAFE-01 §3의 가스 LOTO와 퍼지를 먼저 한다.
3. 챔버 온도와 MFC 주변 온도가 정상 운전 범위에서 안정되어 있다.

## 5. 절차

### 5.1 Zero 점검

1. 유량 설정을 0으로 둔다.
2. MFC 앞뒤 차단 밸브 상태, 입구 압력을 **매번 같은 조건**으로 맞춘다. zero 판독값은 밸브 상태·입구 압력·설치 방향에 따라 달라진다.
3. 안정화 `[예시]` 5분 뒤 판독값을 기록한다.
4. 판정: `[예시]` ±0.5% F.S. 이내 정상, 초과 시 §5.5.

### 5.2 유량 검증 (rate-of-rise)

1. 알려진 부피(챔버 또는 검증용 체적)의 배기를 닫는다.
2. 설정 유량을 흘리며 압력·온도 상승률을 측정해 실제 유량을 계산한다.
3. MFC 표시값과 비교한다. 판정: `[예시]` 설정값의 ±1% 이내 정상.

### 5.3 압력 변동과 etch rate 저하 동반 시

압력 변동과 etch rate 저하가 동반되면 MFC zero와 leak rate를 확인한다.

- 순서: §5.1 zero → §5.4 leak rate → §5.2 유량 검증
- 어느 MFC가 의심되는지 모르면, recipe의 주 식각 가스 MFC부터 본다.
- RF reflected 상승이 함께 있으면 SPEC-RF-03을 병행한다.

### 5.4 챔버 leak rate 확인

1. 기저 압력까지 pump down 한 뒤 배기 밸브를 닫는다.
2. 정해진 시간(`[예시]` 5분) 동안 압력 상승을 기록한다.
3. 판정: 상승률이 `[예시]` 기준값 이하면 정상. 초과하면 O-ring·뷰포트·피드스루 순으로 He leak detector로 위치를 찾는다.

### 5.5 교정·교체 판정

| 결과 | 조치 |
|---|---|
| zero만 벗어남, 유량 검증 정상 | zero 재조정 후 §5.2 재확인 |
| 유량 검증 벗어남 | MFC 교정, 교정 불가 시 교체 |
| 밸브 leak-by 의심 (유량 0인데 압력 상승) | MFC 교체 |
| leak rate 초과 | 누설 위치 수리 후 §5.4 재확인 |

교정·교체 후 SOP-ETCH-12 §4.6 재인증을 한다.

## 6. 기록

- 대상 MFC(가스, 위치, 품번, 일련번호), 점검 시 밸브·입구 압력 조건
- zero 판독값, 유량 검증값, leak rate 측정값과 단위
- 교정·교체 내용과 전후 값
