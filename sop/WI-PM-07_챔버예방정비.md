# WI-PM-07 챔버 예방정비 (Wet clean · Seasoning)

| 항목 | 내용 |
|---|---|
| 문서 ID | WI-PM-07 |
| 개정 | Rev 0.1 (예시, 2026-10-20) |
| 문서 유형 | 작업 지시서(WI) |
| 적용 장비 | 플라즈마 식각 챔버 |
| 관련 문서 | SOP-SAFE-01, SOP-ETCH-12, SPEC-EPD-01 |

> `[예시]` 수치는 시연용이다. 실제 주기·매수·기준은 장비 업체 PM 매뉴얼을 따른다.

## 1. 목적

챔버 벽·전극·endpoint 창에 쌓인 폴리머를 제거하고, 세정 후 흔들린 챔버 상태를 seasoning으로 생산 수준까지 되돌린다.

## 2. 실시 시점

| 구분 | 기준 |
|---|---|
| 정기 PM | RF 누적 시간 또는 처리 매수 중 먼저 도달하는 것 (`[예시]` 3,000매) |
| 비정기 PM | SOP-ETCH-12 조사에서 폴리머 누적 또는 window 오염이 확인 가설로 승인된 경우 |

정기 PM은 장비 상태를 **Scheduled downtime**으로, 비정기 PM은 **Unscheduled downtime**으로 기록한다.

## 3. 절차

### 3.1 세정 전후 값 보존

폴리머 누적 또는 endpoint window 오염이 의심되면 세정 전후 값을 보존하고 seasoning 결과를 기록한다.

- 세정 전: 마지막 정상 run 3건의 etch rate, endpoint 시간, RF reflected power, 챔버 압력, endpoint 신호 세기
- 세정 후: seasoning 각 웨이퍼의 같은 항목, 재인증 결과
- 이 값이 없으면 PM이 효과가 있었는지 다음 조사에서 판단할 수 없으므로 PM을 완료 처리하지 않는다.

### 3.2 사전 준비

1. 진행 중 lot이 없는지 확인하고 챔버를 hold한다.
2. 공정 가스 라인을 닫고 N2 퍼지 `[예시]` 3회를 한다.
3. SOP-SAFE-01 §3에 따라 RF·전기·가스 에너지를 차단·잠금·태그한다.
4. 챔버 부품이 안전 온도 `[예시]` 40 °C 이하로 식을 때까지 기다린다.

### 3.3 Vent와 분해

1. 챔버를 N2로 대기압까지 vent한다.
2. 상부 전극, 챔버 라이너, focus ring, endpoint window를 분리한다.
3. 분리한 부품의 오염 상태를 사진으로 남긴다. 국부적 박리·변색은 별도로 표시한다.

### 3.4 Wet clean과 소모품 교체

1. 부품별 지정 세정액·방법으로 세정한다 (업체 매뉴얼 기준).
2. 교체 대상: O-ring, endpoint window(투과율 기준 미달 시), focus ring(두께 기준 미달 시).
3. 교체 부품의 품번과 lot 번호를 기록한다.

### 3.5 조립과 진공 확인

1. 지정 토크로 조립한다. 토크 미달은 RF 접점 불량과 재현성 저하의 원인이 된다.
2. 기저 압력까지 pump down 한다.
3. rate-of-rise leak check를 한다 (WI-MFC-02 §5.4). 기준을 넘으면 §3.5.1부터 다시 한다.

### 3.6 Dry clean과 seasoning

1. 업체 지정 dry clean recipe로 잔류 세정액·수분을 제거한다.
2. dummy wafer로 seasoning을 한다 (`[예시]` 25매, 생산 recipe와 같은 화학 조건).
3. seasoning 중 마지막 3매의 etch rate가 PM 전 기준 중앙값 ±3% `[예시]` 안에서 안정되면 끝낸다. 안정되지 않으면 `[예시]` 25매를 한 번 더 하고, 그래도 안 되면 SOP-ETCH-12 §4.7로 올린다.
4. seasoning run은 이후 조사의 정상 기준 run으로 쓰지 않는다 (SOP-ETCH-12 §4.3).

### 3.7 재인증과 복귀

SOP-ETCH-12 §4.6과 같다. 복귀 승인 후 장비 상태를 **Productive**로 바꾼다.

## 4. 기록

- PM 구분(정기/비정기), 시작·종료 시각, 작업자
- §3.1의 세정 전후 값, 부품 사진, 교체 부품 품번·lot
- leak check 결과, seasoning 매수와 안정화 결과, 재인증 결과
- 비정기 PM이면 연결된 TRACE 조사 ID
