# 반도체 식각 공정 조사 노트 (SOP 작성 근거)

> 작성 2026-10-20 · 상태: 조사 메모, 공정 전문가 검증 전
> 목적: TRACE가 조사 보고서에서 인용할 SOP를 만들기 전에, 식각 장비에서 무엇이 고장 나고 무엇을 SOP로 확실히 정해 둬야 하는지 정리한다.

## 1. 식각 공정 한눈에 보기

| 구분 | 원리 | TRACE 데이터와의 관계 |
|---|---|---|
| 플라즈마(건식) 식각 — RIE/ICP/CCP | RF 전력으로 공정 가스를 플라즈마로 만들고, 라디칼(화학 반응)과 이온(물리 충돌)으로 막을 제거한다. 가스 유량(MFC), 챔버 압력, RF 전력, 웨이퍼 온도(He 후면 냉각)로 결과를 제어한다. | v1 시연 사례(`db/cases.json`: ETCH-07/09, recipe OX-120)의 etch rate·endpoint·RF reflected·pressure |
| 이온 빔 식각(IBE, ion mill) | 이온 소스에서 만든 Ar 이온을 그리드 전압으로 가속해 웨이퍼를 물리적으로 깎는다. 웨이퍼는 회전·기울기 고정구 위에 있고, 셔터로 시작 전 빔을 가리며, 중화기(PBN)가 빔 모양을 조정한다. 웨이퍼는 He/물 FlowCool로 냉각하고 O-ring이 He와 진공 챔버를 분리한다. | PHM 2018 데이터(표준화 센서값, FlowCool 고장 3종) |
| 습식 식각 | 약액에 담가 화학적으로 제거한다. | 범위 밖 |

공통 제어 축은 **에너지(RF·빔 전압/전류) · 가스(유량·압력) · 온도(후면 냉각) · 종료 판정(endpoint 또는 시간)** 네 가지다. 이상 조사는 결국 이 네 축 중 어느 것이 기준에서 벗어났는지를 run 비교로 좁히는 일이다.

## 2. 알려진 이상 메커니즘

| 메커니즘 | 주로 보이는 증상 | 확인 대상 | 근거 |
|---|---|---|---|
| 챔버 벽·전극 폴리머 누적 | etch rate 저하, endpoint 지연, 시간에 따른 drift | 마지막 PM 이후 RF 시간·처리 매수, wet clean 이력 | 세정 직후 벽 상태가 바뀌어 etch rate·균일도가 흔들리고, seasoning으로 정상 상태로 되돌린다 (US 9230782, US 7147748) |
| Endpoint 창(window) 오염 | OES 신호 세기 감소 → endpoint 지연·오검출 | 창 투과율, 신호 gain, 광원 | 창 안쪽 면에 폴리머·반응 부산물이 쌓여 빛을 흡수·산란하고, endpoint 신호가 약해져 판정이 틀어진다 (US 5966586, US 6919279) |
| RF match network 열화 | reflected power 상승, 전달 전력 감소 → etch rate·균일도 변화, 플라즈마 불안정 | 가변 커패시터·스텝 모터, 튜닝 알고리즘, preset, 접점 | 커패시터·모터 열화, 튜닝 알고리즘 이상, preset 설정 오류가 원인 후보 (Advanced Energy). VSWR만 보지 말고 insertion loss를 함께 추적 (Bird) |
| MFC zero drift·밸브 leak-by | 압력 불안정, etch rate 저하 | zero offset, 실제 유량(rate-of-rise) | zero 판독값은 차단 밸브 상태·입구 압력·설치 방향에 따라 달라지므로 같은 조건에서 측정해야 한다 (US 9739655). rate-of-rise로 실제 유량을 검증한다 (US 7174263) |
| 챔버 진공 누설 | 기저 압력 상승, 공정 압력 불안정 | rate-of-rise leak check | 같은 rate-of-rise 원리 |
| He 후면 냉각 누설(O-ring·클램프·척) | 냉각 압력·유량 이상, 웨이퍼 온도 상승 | O-ring, 클램프 손상, 척 오염, 웨이퍼 뒷면 | 새 부품일 때 He 유량 기준값을 잡아 두고 유량이 오르면 O-ring 교체·척 세정을 한다 (MIT labnetwork 2018, 실무자 메일링리스트) |
| 이온 소스 그리드 마모·단락(IBE) | 빔 전류·서프레서 전류 변화, 단락 알람 | 그리드 사용 카운터, 그리드 간 퇴적물 | 전하 교환 이온이 그리드를 깎고, 스퍼터 퇴적물·박리 조각이 그리드 사이에 끼면 단락이 생긴다 (US 10014164, NASA/JPL) |

PHM 2018의 고장 3종(FlowCool Pressure Dropped Below Limit, Flowcool Pressure Too High Check Flowcool Pump, Flowcool leak)은 위 표의 "He 후면 냉각" 계열에 해당한다. **기록된 고장 시각은 운영자가 정비하려고 장비를 멈춘 시각**이며 실제 고장 시작 시점이 아니다 (PHM Society).

## 3. 장비 관리의 틀

- **장비 상태(SEMI E10):** Productive / Standby / Engineering / Scheduled downtime(PM·셋업) / Unscheduled downtime(비계획 정비·abort) / Non-scheduled. 이상이 감지되면 누가 어떤 상태로 바꾸는지를 SOP에 박아 둬야 가동률 집계와 책임 소재가 흔들리지 않는다.
- **정비 흐름:** 정지·격리 → 분해·세정·부품 교체 → 조립·pump down·leak check → dry clean·seasoning → 재인증(monitor wafer) → 생산 복귀. 문헌에서는 wet clean·seasoning·재인증에 최대 24시간이 걸린다고 하고, 한 장비 모델은 3,000매마다 wet clean한 사례가 있다 (US 6197699).
- **안전(SEMI S2):** 정비 전 전기·RF·가스·진공·냉각수·열 에너지를 식별하고 차단·잠금·태그(LOTO)한 뒤 잔류 에너지를 없앤다. 가스 라인은 닫고 퍼지한 다음에 분리한다 (US 11906072).

## 4. SOP에 반드시 정해야 하는 것

조사 결과를 보면, 조사 Agent가 근거로 쓰려면 SOP가 아래 항목을 **애매하지 않게** 갖고 있어야 한다.

1. **트리거:** 어떤 신호가 어떤 기준을 넘으면 이 SOP를 시작하는가 (수치·비교 기준 run 정의 포함)
2. **즉시 조치:** 장비 hold/abort 여부, 진행 중 웨이퍼 처리, E10 상태 전환과 그 권한자
3. **점검 순서:** 계통별로 무엇을 먼저 보는가 (비용이 작고 가능성이 큰 것부터)
4. **판정 기준:** 정상/주의/이상 경계값과 단위 — 단위가 없는 데이터(PHM 표준화 값)는 z-score로만
5. **역할:** 접수(worker), 조사·판정·승인(engineer), 조회·문서 관리(admin)
6. **복귀 조건:** 재인증 항목과 합격 기준, 실패 시 에스컬레이션
7. **기록:** 조치 전후 값, 교체 부품, 근거 run·문서 조항 ID

## 5. 이 폴더의 SOP와 TRACE 연결

`db/documents.json`이 이미 5개 조항 ID를 쓰고 있다. 같은 ID로 전체 문서를 만들고 **기존 조항 문장을 그대로 유지**했다. 그래서 `cases.json`의 `docs` 참조가 끊기지 않는다. 문서 MCP(`mcp/rag.py`)는 `문서ID#조항` 형식의 정확한 ID로 조회하므로, 조항 번호는 바꾸지 않는다.

## 6. 한계

- 검색 결과는 대부분 특허·장비 업체 블로그·실무자 메일링리스트다. 장비 업체 정비 매뉴얼과 SEMI 표준 원문은 확인하지 못했다.
- 그래서 SOP의 수치(%·매수·시간)는 모두 **`[예시]` 시연용 값**이다. 실제 장비 매뉴얼과 공정 스펙으로 확정하기 전에는 판정에 쓰지 않는다.
