> **샘플 문서**: 시연용 예시입니다. 실제 fab에서는 처분 판정을 MRB(불량 자재 심의) 절차로 합니다.

## 1. 목적 및 적용 범위

설비 이상으로 품질이 의심되는 lot을 보류(hold)하고, 처분과 해제(release)를 누가 어떤 근거로 승인하는지 정합니다. OCAP 또는 SOP-ETCH-12에서 lot hold가 필요할 때 적용합니다.

## 2. 용어

| 용어 | 뜻 |
| --- | --- |
| Hold | MES에서 lot의 다음 공정 진행을 막는 상태 |
| Release | Hold를 풀어 다음 공정으로 보내는 결정 |
| 처분 | Release, 추가 계측, rework, scrap 중 하나를 정하는 결정 |
| 마지막 정상 확인 | 이상 챔버에서 정상으로 확인된 마지막 monitor 또는 계측 시점 |

## 3. 역할과 책임

| 역할 | 할 일 |
| --- | --- |
| worker | Hold 실행, 사유와 연결 조사 ID 입력 |
| engineer | Hold 범위 결정, 처분 판정, Release 승인 |
| 품질 담당 | Scrap 승인, 장기 hold 검토 |
| admin | 조회 |

## 4. 절차

### 4.1 Hold 대상 판정

아래 중 하나에 해당하면 hold합니다.

- 인터락 abort로 처리가 중단된 웨이퍼가 있는 lot
- OCAP Activator가 발생한 챔버에서 §4.2 범위 안에 처리된 lot
- 후속 계측에서 해당 챔버가 원인으로 지목된 lot

### 4.2 Hold 범위 결정

1. 마지막 정상 확인 이후 해당 챔버에서 처리된 모든 lot을 기본 범위로 잡습니다.
2. 알람 시각은 이상 시작 시각이 아니므로, SOP-ETCH-12 §4.3에서 이상 시작이 더 앞으로 확인되면 범위를 넓힙니다.
3. 같은 recipe의 다른 챔버에도 이상이 있으면 그 챔버의 lot도 범위에 넣습니다.

### 4.3 Hold 실행

1. MES에서 hold 코드와 사유를 입력합니다.
2. 연결된 TRACE 조사 ID와 OCAP ID를 적습니다.
3. Hold 시각과 실행자를 남깁니다.

### 4.4 처분 판정 기준

| 조건 | 처분 |
| --- | --- |
| 계측 결과가 스펙 안이고, 조사에서 해당 lot 처리 시점에 이상이 없었음 | Release |
| 이상 run에 처리됐으나 계측 전 | 추가 계측 후 재판정 |
| 계측 결과가 스펙 밖이고 재작업 가능 | Rework |
| 계측 결과가 스펙 밖이고 재작업 불가 | Scrap (품질 담당 승인) |

### 4.5 Release 승인

1. Release는 engineer만 승인합니다.
2. 조사 보고서 승인 전에는 계측으로 스펙 안이 확인된 lot만 release합니다.
3. 승인자, 승인 시각, 근거(계측 결과, 조사 ID)를 남깁니다.

### 4.6 장기 hold

Hold가 `[예시]` 24시간을 넘으면 품질 담당이 검토하고, `[예시]` 72시간을 넘으면 SOP-ETCH-12 §4.9로 올립니다.

## 5. 판정 기준·검증

- Release와 scrap 판정은 hold를 실행한 사람이 아닌 승인자가 합니다.
- 처분 근거가 되는 계측 결과는 원본 데이터 ID를 함께 남깁니다.

## 6. 기록 관리

Lot ID, wafer ID, hold 사유·코드, hold 시각·실행자, 연결 조사 ID·OCAP ID, 계측 결과, 처분, 승인자·승인 시각을 남깁니다.
