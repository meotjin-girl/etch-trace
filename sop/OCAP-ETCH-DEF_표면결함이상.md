# OCAP-ETCH-DEF 파티클·스크래치·표면 결함 대응

| 담당 팀 | 버전 | 최근 개정 |
| --- | --- | --- |
| Etch공정기술팀 | 1.0 | 2026-10-20 |

## 1. 적용 범위

| 항목 | 내용 |
| --- | --- |
| 장비 유형 | Plasma Etch / Ion Mill |
| 공정·감시 항목 | 파티클, scratch, cluster, edge ring, residue, defect density |
| 필요 데이터 | 식각 전후 defect map·좌표·이미지, 검사 recipe·민감도, 반송·고정·PM·부품 이력 |
| 검증 가능 범위 | 결함 증가와 공간 공통성 분석 가능. 결함 검사 데이터와 현장 확인 필요 |

> PHM 2018에는 defect map·검사 이미지가 없습니다. 기술 근거: SRC-KLA-DEF, SRC-PHM-2018.

## 2. Activator

- 경고: defect 증가량 또는 특정 공간 패턴이 주의 한계를 넘음
- 이상: 파티클 수, defect density 또는 결함 증가량이 관리 한계를 벗어남
- 중대 이상: scratch·wafer 손상, 다수 wafer의 급증 또는 제품 스펙 이탈

## 3. 즉시 조치

1. 검사 recipe를 변경하지 않고 원본 map·좌표·이미지를 보존합니다.
2. 영향 lot을 SOP-ETCH-20에 따라 hold하고 chamber 공통성을 확인합니다.
3. 파손이나 반송 안전 위험이 있으면 승인된 장비 정지 절차를 따릅니다.

## 4. Checkpoints

### 4.1 결함과 검사 신뢰성

#### 시나리오: 신규 Particle·Cluster

- 관측: pre/post defect map의 동일 좌표 매칭으로 신규·증가 결함을 봅니다.
- 필요 데이터·존재 여부: 검사 recipe·민감도·좌표·이미지가 필요하며 PHM에는 없습니다.
- 비교 Run: 동일 제품·검사 조건의 대상 이전 run과 pre-etch map을 비교합니다.
- 패턴→후보: chamber 좌표의 cluster면 박리·오염, lot 공통이면 유입·검사 조건을 우선합니다.
- 지지 근거: 신규 좌표, 성분·형상 일치, 특정 chamber 재현입니다.
- 반대 근거: pre-map에 존재하거나 검사 민감도 변경으로 증가가 설명됩니다.
- 판단 불가: pre-map이 없으면 신규 발생과 유입을 확정 구분할 수 없습니다.
- 추가 확인: 동일 좌표 재검, 성분 분석, chamber·PM 이력을 확인합니다.
- 이동 조건·조사 결과: 정비·박리 연관이면 PM, 진공 잔류 연관이면 VAC로 이동해 판정을 기록합니다.

#### 시나리오: Scratch

- 관측: 선형 결함의 방향·길이·반복 위치와 wafer 손상을 봅니다.
- 필요 데이터·존재 여부: 고해상도 이미지, wafer/장비 좌표, robot·fixture event가 필요합니다.
- 비교 Run: 같은 slot·경로·장착 방향의 이전 wafer와 pre/post 이미지를 비교합니다.
- 패턴→후보: 동일 경로·방향이면 반송·접촉·fixture, 무작위면 검사 artifact나 다른 공정을 우선합니다.
- 지지 근거: event 시점, 접촉 위치 대응, 반복 방향성입니다.
- 반대 근거: pre-etch 이미지에 존재하거나 장비 좌표와 무관합니다.
- 판단 불가: 좌표 기준이나 반송 log가 없으면 발생 위치를 특정할 수 없습니다.
- 추가 확인: robot·aligner·lift pin·fixture를 승인 절차로 점검합니다.
- 이동 조건·조사 결과: Ion Mill fixture이면 MOTION, Plasma chuck이면 ESC로 이동하고 손상 영향도와 근거를 기록합니다.

### 4.2 공간·장비 공통성

#### 시나리오: Edge 결함

- 관측: edge ring·bevel·특정 방위각에 집중되는 결함을 봅니다.
- 필요 데이터·존재 여부: edge 포함 map·이미지, notch 방향, clamp/focus ring/fixture 정보가 필요합니다.
- 비교 Run: 같은 edge 검사 recipe와 장착 방향의 이전 run을 비교합니다.
- 패턴→후보: 장비 방향 고정이면 접촉·부품, wafer 방향 고정이면 incoming을 우선합니다.
- 지지 근거: 공간 재현성과 관련 부품·event의 독립 증거입니다.
- 반대 근거: 검사 edge exclusion 변경이나 pre-map으로 설명됩니다.
- 판단 불가: edge 검사 범위가 다르면 결함 수를 직접 비교할 수 없습니다.
- 추가 확인: 좌표 정렬, 접촉부와 부품 상태, pre-map을 확인합니다.
- 이동 조건·조사 결과: 균일도 동반이면 UNI, 고정 event면 MOTION/ESC로 이동해 결과를 기록합니다.

### 4.3 반송·오염·PM 이력

#### 시나리오: Residue·막잔사

- 관측: 잔사의 위치·형상·조성과 식각 깊이·endpoint 이상 동반 여부를 봅니다.
- 필요 데이터·존재 여부: 이미지·성분·profile·recipe·endpoint가 필요하며 PHM에는 품질·endpoint가 없습니다.
- 비교 Run: 같은 막·mask·recipe·측정 조건의 대상 이전 run을 비교합니다.
- 패턴→후보: 미식각과 동반되면 공정 조건·종료, 국부 오염이면 chamber·incoming을 우선합니다.
- 지지 근거: profile·성분 및 관련 공정 신호의 일치입니다.
- 반대 근거: 식각 전부터 존재하거나 후속 세정/검사 artifact입니다.
- 판단 불가: 이미지 단독으로 화학 조성이나 발생 공정을 확정할 수 없습니다.
- 추가 확인: 성분·단면 계측과 EPD/RATE·공정 센서를 조회합니다.
- 이동 조건·조사 결과: 미식각이면 RATE/EPD, chamber 이력이면 PM으로 이동하고 미확인을 기록합니다.

### 4.4 원인 후보와 추가 검증

공간 형태만으로 특정 고장 부품을 확정하지 않습니다. 신규 결함 여부, 성분·좌표, 지지·반대 증거와 현장 추가 확인 결과를 분리 기록합니다.

## 5. Terminator

- 조사 종결: 신규 결함 여부, 영향 범위, 원인 후보와 추가 검증이 기록됨
- 장비 복귀: 신규 결함이 승인 기준 안이고 필요한 재검사·재인증을 통과함
- Lot 처분: 품질 판정과 SOP-ETCH-20에 따라 별도로 승인함

## 6. 에스컬레이션

wafer 파손·연속 scratch·대량 파티클이면 즉시 설비·품질 담당에게 올립니다. 성분 분석이나 이전 공정 확인이 필요하면 해당 계측·공정 담당에게 올립니다.
