# SOP-SAFE-01 정비 착수·복귀 공통 (장비 상태 · LOTO)

| 항목 | 내용 |
|---|---|
| 문서 ID | SOP-SAFE-01 |
| 개정 | Rev 0.1 (예시, 2026-10-20) |
| 적용 장비 | 식각 장비 전체 |
| 관련 표준 | SEMI E10(장비 상태), SEMI S2(장비 EHS 가이드라인) |
| 관련 문서 | 모든 식각 SOP·WI |

> 이 문서는 시연용 예시다. 실제 LOTO 절차는 사업장 EHS 규정과 장비 업체 안전 매뉴얼이 우선한다.

## 1. 목적

정비를 시작하고 끝낼 때 장비 상태를 누가 어떻게 바꾸는지, 장비를 열기 전에 어떤 에너지를 차단하는지 정한다.

## 2. 장비 상태 (SEMI E10)

### 2.1 상태 정의

| 상태 | 뜻 | 예 |
|---|---|---|
| Productive | 장비가 본래 기능을 수행 중 | 생산 lot 처리 |
| Standby | 돌릴 수 있으나 돌지 않음 | 대기 lot 없음, 작업자 부재 |
| Engineering | 실험·평가 목적 가동 | 공정 개발, 재인증 run |
| Scheduled downtime | 계획된 정지 | 정기 PM, 셋업 |
| Unscheduled downtime | 계획에 없던 정지 | 고장, 알람 abort, 비정기 PM |
| Non-scheduled | 가동 계획 없음 | 비가동 근무조 |

### 2.2 전환 권한

| 전환 | 실행 | 승인 |
|---|---|---|
| 생산 → Unscheduled downtime | worker (알람·이상 감지 즉시) | 사후 engineer 확인 |
| 생산 → Scheduled downtime | worker | PM 계획 |
| downtime → Engineering (재인증 run) | worker | engineer |
| Engineering → Productive | worker | engineer (재인증 합격 후) |

상태 전환 시각은 조사 기록의 기준 시각이 되므로 실제 전환 시점에 바로 입력한다.

## 3. 에너지 차단 (LOTO)

### 3.1 에너지원 식별

장비를 열기 전에 아래 에너지원을 모두 확인한다.

| 에너지 | 예 | 잔류 에너지 처리 |
|---|---|---|
| 전기 | 주전원, 히터 | 차단 후 무전압 확인 |
| RF | generator, match | 출력 차단, 커패시터 방전 대기 |
| 고전압 (IBE) | 이온 소스 그리드 전원 | 차단 후 방전 확인 |
| 가스 | 공정 가스, He | 밸브 잠금 후 퍼지·잔압 해소 |
| 진공 | 챔버 | N2 vent로 대기압 |
| 냉각수·열 | chiller, 고온 부품 | 유로 차단, 안전 온도까지 냉각 |

### 3.2 절차

1. **통보:** 장비 주변 작업자와 해당 라인에 정비 시작을 알린다.
2. **정지:** 정상 정지 절차로 장비를 멈춘다.
3. **차단:** §3.1의 각 에너지 차단 장치를 끈다.
4. **잠금·태그:** 차단 장치마다 개인 자물쇠와 태그(이름, 날짜, 사유)를 단다. 여러 명이 작업하면 각자 자물쇠를 단다.
5. **잔류 에너지 해소:** §3.1의 오른쪽 열대로 처리한다. 가스 라인은 닫고 퍼지한 뒤에 분리한다.
6. **검증:** 시동을 시도해 실제로 켜지지 않는지, 측정기로 무전압·대기압인지 확인한다.

### 3.3 해제

1. 공구·부품 회수, 덮개 조립을 확인한다.
2. 작업자 전원이 철수했는지 확인한다.
3. 자물쇠는 단 사람이 직접 푼다.
4. 에너지를 차례로 복구하고 해당 SOP의 복귀 절차(재인증)로 넘어간다.

## 4. 기록

- 정비 시작·종료 시각, 상태 전환 시각과 실행자·승인자
- 차단한 에너지원 목록, 자물쇠 부착자, 검증 결과
