## 작성 규칙

- **조항 ID는 바꾸지 않는다.** 문서 MCP(`mcp/rag.py`)가 `문서ID#조항`으로 정확히 조회하고, `db/cases.json`이 이 ID를 참조한다. 기존 5개 조항의 첫 문장은 `documents.json`의 `text`와 똑같다.
- 문서 머리 표: 문서 ID, 개정, 적용 장비, 관련 문서.
- 본문에 반드시 넣는 것: 트리거와 기준값, 즉시 조치와 장비 상태 전환, 점검 순서, 판정 기준(단위 포함), 역할(worker/engineer/admin), 복귀 조건, 기록 항목.
- 원인은 "확인 가설"로 쓰고 단정하지 않는다.
- PHM 데이터는 표준화 값이라 물리 단위를 붙이지 않고 z-score로만 쓴다. 고장 기록 시각은 정지 시각이지 고장 시작 시각이 아니다.
