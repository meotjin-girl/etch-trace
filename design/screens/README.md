# screens — 역할별 화면

| 폴더 | 사용자 | 주요 화면 |
|---|---|---|
| `worker/` | 작업자 | 대화형 조사 요청, 재질문 답변, 내 요청 진행 · 결과 |
| `engineer/` | 장비 · 공정 엔지니어 | 배정 목록, 조사 진행 관찰, 보고서 검토 · 수정 요청 · 분류 정정 · 승인 |
| `admin/` | 관리자 | 전체 이력, 분류 비율, 엔지니어 부하, 미배정 건 배정 |
| `shared/` | 공통 | 로그인 · 역할 선택, 공통 레이아웃 · 내비게이션 |

화면 1개 = 폴더 1개 (`engineer/review/`) 안에 와이어프레임 · 목업 이미지와 `README.md`(목적 · 진입 경로 · 사용 컴포넌트 · 상태별 화면)를 둡니다.
