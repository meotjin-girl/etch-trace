# references — 레퍼런스 수집 규칙

## 어디에 넣을까

| 무엇을 참고하나 | 폴더 |
|---|---|
| 한 제품의 전반적인 경험 (여러 화면) | `products/{제품명}/` |
| 특정 UI 패턴 (여러 제품 비교) | `patterns/{패턴}/` |
| 색 · 타이포 · 아이콘 · 레이아웃 | `visual/{분야}/` |
| 반도체 · 제조 현장 화면 | `domain/{분야}/` |

한 장이 여러 곳에 해당하면 **가장 구체적인 폴더 하나**에만 넣고, 나머지는 INDEX의 태그로 표시합니다.

## 파일 이름

```
{YYYYMMDD}_{출처}_{내용}.{확장자}
예) 20261020_linear_issue-timeline.webp
    20261020_grafana_anomaly-panel.png
```

## 기록

저장할 때마다 [`INDEX.md`](INDEX.md)에 한 줄을 추가합니다. **참고 포인트가 없는 레퍼런스는 넣지 않습니다.**

## 공개 레포 주의

이 레포는 공개 저장소입니다. 타사 제품 스크린샷은 저작권 대상이므로,

- 공개 웹페이지 · 공식 문서 · 공개 디자인 사례는 **링크 + 핵심 부분 캡처**만 저장
- 로그인 뒤 화면, 유료 키트, 사내 · 고객사 화면은 **저장 금지** (링크와 설명만)
- 캡처에는 출처를 INDEX에 반드시 기록
