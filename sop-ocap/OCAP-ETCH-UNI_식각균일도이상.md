# OCAP-ETCH-UNI 식각 균일도 이상 대응

| 담당 팀 | 버전 | 최근 개정 |
| --- | --- | --- |
| Etch공정기술팀 | 1.0 | 2026-10-20 |

## 1. 적용 범위

| 항목 | 내용 |
| --- | --- |
| 장비 유형 | Plasma Etch / Ion Mill |
| 공정·감시 항목 | wafer 내·wafer 간 식각 균일도, 위치별 식각 깊이·속도 |
| 필요 데이터 | 식각 전후 wafer map, 측정 좌표·계산식, recipe·step, 냉각·고정·회전, chamber·PM 이력 |
| 검증 가능 범위 | 공간 패턴과 장비 공통성 분석 가능. 원인 확정에는 계측 원본과 현장 점검 필요 |

> PHM 2018에는 wafer map·균일도 계측값이 없습니다. 기술 근거: SRC-LAM-CORVUS, SRC-PHM-2018.

## 2. Activator

- 경고: Center–Edge 또는 방향성 편차가 관리 한계의 주의 영역에 있거나 증가 추세임
- 이상: Within-Wafer 또는 Wafer-to-Wafer Uniformity가 승인된 관리 한계를 벗어남
- 중대 이상: 제품 스펙 이탈 또는 여러 wafer에서 같은 위치 패턴이 반복됨

## 3. 즉시 조치

1. 식각 전후 wafer map과 원본 좌표를 보존합니다.
2. 영향 lot을 SOP-ETCH-20에 따라 hold하고 같은 chamber의 후속 투입 여부를 engineer가 결정합니다.

## 4. Checkpoints

### 4.1 공간 패턴과 계측

#### 시나리오: Center–Edge 편차

- 관측: 식각 전후 map에서 중심-가장자리 radial 패턴과 edge 폭을 봅니다.
- 필요 데이터·존재 여부: 원본 좌표·계산식·식각 전후 map이 필요하며 PHM에는 없습니다.
- 비교 Run: 동일 제품·막·recipe·chamber·측정 좌표의 대상 이전 run을 비교합니다.
- 패턴→후보: 반복 radial 패턴이면 edge 환경·focus ring·열경계, 식각 전부터 있으면 투입막을 우선합니다.
- 지지 근거: 같은 반경에서 wafer 간 재현되고 부품·온도 이력과 시점이 맞습니다.
- 반대 근거: 좌표·검사 recipe 변경으로만 차이가 나거나 식각 전 map으로 설명됩니다.
- 판단 불가: map 없이 요약값만 있으면 공간 원인을 분리할 수 없습니다.
- 추가 확인: focus ring·냉각·PM 및 식각 전 map을 확인합니다.
- 이동 조건·조사 결과: 열 신호면 TMP/ESC, 부품 이력이면 PM으로 이동하고 판정 상태를 기록합니다.

### 4.2 장비·공정 조건

#### 시나리오: 방향성 편차

- 관측: 특정 방위각·sector·한쪽 edge에 반복되는 편차를 봅니다.
- 필요 데이터·존재 여부: 방향 기준이 보존된 map, 회전·고정구·가스분배 정보가 필요합니다.
- 비교 Run: notch 방향과 장착 방향이 같은 대상 이전 run 및 다른 chamber를 비교합니다.
- 패턴→후보: 장비 좌표에 고정되면 분포·고정구, wafer 좌표에 고정되면 투입막·이전 공정을 우선합니다.
- 지지 근거: 방향 정렬 후 패턴 재현, 회전/fixture 이벤트와 동시 변화입니다.
- 반대 근거: 좌표 변환 시 패턴이 사라지거나 검사기 방향에만 고정됩니다.
- 판단 불가: wafer·장비 좌표 변환 정보가 없으면 방향 원인을 판단할 수 없습니다.
- 추가 확인: 좌표 정렬, MOTION 설정·실제각, 가스·RF/beam 분포를 확인합니다.
- 이동 조건·조사 결과: 회전·fixture 연관이면 MOTION, 표면 결함이면 DEF로 이동하고 근거를 기록합니다.

#### 시나리오: Wafer 간 편차 증가

- 관측: lot 내 평균은 비슷하나 wafer-to-wafer 분산이 커지는지 봅니다.
- 필요 데이터·존재 여부: wafer별 map, 처리 순서, 초기막·냉각·chamber 상태가 필요합니다.
- 비교 Run: 동일 조건의 과거 lot과 lot 내 시간 순서를 비교합니다.
- 패턴→후보: 처리 순서에 따라 변하면 conditioning·열상태, 특정 wafer만이면 투입·고정·계측을 우선합니다.
- 지지 근거: 순서 재현, 센서/상태 전환 동반, 재측정 일치입니다.
- 반대 근거: 검사 반복성이 낮거나 초기막 편차가 결과를 설명합니다.
- 판단 불가: wafer ID와 처리 순서가 없으면 시간 의존성을 판단할 수 없습니다.
- 추가 확인: 초기막 map, step별 센서, 냉각·고정 event를 조회합니다.
- 이동 조건·조사 결과: 고정·냉각이면 ESC/TMP, conditioning이면 PM으로 이동해 결과를 기록합니다.

### 4.3 PM과 부품 상태

#### 시나리오: Focus ring·냉각·고정구 변화

- 관측: 부품 교체·세정 또는 냉각·고정 event 전후 map 형태 변화를 봅니다.
- 필요 데이터·존재 여부: 실제 PM 기록, 부품 ID, He/ESC 또는 fixture 데이터가 필요하며 PHM에는 실제 PM·ESC 데이터가 없습니다.
- 비교 Run: 변경 직전·직후 동일 조건과 과거 동일 작업 사례를 비교합니다.
- 패턴→후보: Plasma edge 변화는 focus ring·열경계, Ion Mill 방향성 변화는 회전·fixture를 우선합니다.
- 지지 근거: 경계 시점 일치와 관련 event·센서의 독립 증거입니다.
- 반대 근거: 변경 전부터 진행되거나 전 chamber 공통입니다.
- 판단 불가: 시간적 연관만으로 부품 원인을 확정할 수 없습니다.
- 추가 확인: 승인된 부품 점검과 재인증 map을 확인합니다.
- 이동 조건·조사 결과: PM/MOTION/ESC 중 증거가 있는 OCAP으로 이동하고 후보별 지지·반대를 기록합니다.

### 4.4 원인 후보와 추가 검증

Wafer map 형태만으로 특정 장비나 부품을 원인으로 확정하지 않습니다. 모든 시나리오의 비교 조건, 지지·반대 증거, 미확인 사항과 연결 OCAP을 조사 결과에 남깁니다.

## 5. Terminator

- 조사 종결: 공간 패턴, 계측 신뢰성, 영향 범위와 원인 후보가 기록됨
- 장비 복귀: 승인된 균일도 기준과 SOP-ETCH-01 §4.8 재인증을 만족함
- Lot 처분: 추가 계측 결과에 따라 SOP-ETCH-20으로 별도 승인함

## 6. 에스컬레이션

식각 전 map이 없거나 chamber와 투입막 영향을 구분할 수 없으면 계측·공정 담당에게 올립니다. 스펙 이탈 또는 반복 패턴은 품질 담당에게 올립니다.
