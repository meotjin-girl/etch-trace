# OCAP-ETCH-RATE 식각 속도 이상 대응

| 담당 팀 | 버전 | 최근 개정 |
| --- | --- | --- |
| Etch공정기술팀 | 1.0 | 2026-10-20 |

## 1. 적용 범위

| 항목 | 내용 |
| --- | --- |
| 장비 유형 | Plasma Etch / Ion Mill |
| 공정·감시 항목 | 식각 step, etch rate, 식각 깊이, 공정 시간 |
| 필요 데이터 | 식각 전후 막 두께·측정 위치, recipe·step, RF/Bias 또는 beam, 가스·압력·냉각, PM·seasoning 이력 |
| 검증 가능 범위 | 계측과 운전 데이터가 있으면 추세·연관성 분석 가능. 원인 확정에는 추가 계측 또는 현장 점검 필요 |

> PHM 2018에는 식각 속도·막 두께 계측값이 제공되지 않습니다. 해당 데이터가 없으면 본 OCAP은 원인 후보와 추가 조회 항목만 제시합니다. 기술 근거: SRC-LAM-ETCH, SRC-PHM-2018.

## 2. Activator

- 경고: etch rate가 승인된 관리 한계의 주의 영역에 있거나 이전 lot 대비 지속적으로 변함
- 이상: etch rate 또는 목표 식각 깊이가 공정 스펙·관리 한계를 벗어남
- 중대 이상: 과식각·미식각으로 제품 영향이 예상되거나 같은 조건에서 연속 재발함

## 3. 즉시 조치

1. 계측 원본, 대상 wafer·lot, 장비·챔버·recipe·step을 보존합니다.
2. 영향 lot은 SOP-ETCH-20의 승인된 절차로 hold하고 범위를 확인합니다.
3. 중대 이상이면 다음 lot 투입을 중지하고 engineer에게 통보합니다.

## 4. Checkpoints

### 4.1 계측과 투입 조건

#### 시나리오: 식각 속도 급변

- 관측: 동일 조건의 직전 분포에서 식각 속도가 갑자기 이동했는지 봅니다.
- 필요 데이터·존재 여부: 식각 전후 막 두께·측정 위치·계측 recipe가 필수이며 PHM 2018에는 없습니다.
- 비교 Run: 대상 이전의 동일 제품·막·recipe·chamber·계측 조건 run을 우선합니다.
- 패턴→후보: 단일 측정만 이동하면 계측·투입막, 다수 wafer와 공정 신호가 함께 이동하면 에너지·가스·압력 변화를 우선합니다.
- 지지 근거: 반복 계측 재현, 관련 신호의 같은 시점 변화, 다른 wafer 재발입니다.
- 반대 근거: 재측정 정상, 초기 막 차이로 계산값이 설명됨, 공정 신호와 다른 chamber가 안정적입니다.
- 판단 불가: 전·후 두께 또는 단위·좌표가 없으면 실제 속도 변화인지 판단할 수 없습니다.
- 추가 확인: 계측 원본 재검토 후 RF/BEAM, GAS, PRS 데이터를 조회합니다.
- 이동 조건·조사 결과: 동반 신호에 따라 해당 OCAP으로 이동하고 `확인/기각/미결`과 근거를 기록합니다.

### 4.2 공정 조건과 관련 계통

#### 시나리오: 장기 Drift

- 관측: 동일 조건의 대상 이전 run에서 식각 속도 중심값과 분산이 서서히 변하는지 봅니다.
- 필요 데이터·존재 여부: 연속 계측, recipe·step, chamber 사용량과 센서 추세가 필요하며 PHM에는 품질 계측이 없습니다.
- 비교 Run: 미래 정보 없이 대상 이전의 같은 조건 run을 시간순으로 비교합니다.
- 패턴→후보: 사용량과 함께 단조 이동하면 chamber·부품 상태, 가스·압력과 함께 이동하면 해당 계통을 우선합니다.
- 지지 근거: 여러 lot의 재현성과 독립 계측·센서의 같은 방향 변화입니다.
- 반대 근거: 제품·막·계측기 변경 시점과만 일치하거나 chamber 간 공통으로 발생합니다.
- 판단 불가: 사용량 카운터는 순간 센서가 아니며 drift 자체로 마모를 확정할 수 없습니다.
- 추가 확인: 계측기 교차 확인, chamber 이력, GAS·PRS·RF/BEAM·TMP 추세를 조회합니다.
- 이동 조건·조사 결과: 특정 계통과 공변하면 해당 OCAP, 누적 상태와 연관되면 PM으로 이동해 판정 상태를 기록합니다.

### 4.3 Chamber 상태

#### 시나리오: PM 직후 변화

- 관측: PM·세정·부품 교체·seasoning 전후의 식각 속도 불연속을 봅니다.
- 필요 데이터·존재 여부: 실제 PM 작업·부품·교정·seasoning 기록이 필요하며 PHM에는 실제 PM 이력이 없습니다.
- 비교 Run: PM 직전과 직후의 동일 조건 run 및 과거 동일 정비 사례를 비교합니다.
- 패턴→후보: 직후부터 지속되면 조립·교정·conditioning, 일시적이면 seasoning 영향을 우선합니다.
- 지지 근거: 정비 경계와 변화 시점 일치, 재인증 실패, 동일 작업 후 재발입니다.
- 반대 근거: 변화가 PM 전에 시작되었거나 다른 chamber·제품에도 동시에 나타납니다.
- 판단 불가: 시간적 선후만으로 PM을 원인으로 확정할 수 없습니다.
- 추가 확인: 작업 기록과 정비 관련 센서, 승인된 재인증 결과를 확인합니다.
- 이동 조건·조사 결과: 정비 관련성이 남으면 OCAP-ETCH-PM으로 이동하고 인과 여부를 미결로 분리 기록합니다.

### 4.4 원인 후보와 추가 검증

#### 시나리오: Chamber 편차

- 관측: 같은 제품·recipe가 특정 chamber에서만 이동하는지 봅니다.
- 필요 데이터·존재 여부: chamber 식별자와 교차 chamber 계측이 필요하며 현장 데이터 존재 여부를 확인합니다.
- 비교 Run: 같은 시간대·투입막·계측 조건의 다른 chamber와 대상 chamber 과거 run을 비교합니다.
- 패턴→후보: 특정 chamber에 한정되면 chamber 상태·부품·보정, 전 chamber 공통이면 투입막·계측·utility를 우선합니다.
- 지지 근거: chamber 재현성, swap/재인증 결과, 관련 센서 차이입니다.
- 반대 근거: lot 또는 계측기 기준으로 묶이고 chamber를 바꿔도 지속됩니다.
- 판단 불가: 비동등 recipe·제품의 단순 평균 비교로 chamber 효과를 판단할 수 없습니다.
- 추가 확인: matched-run 구성, PM·seasoning 및 관련 품질 map을 조회합니다.
- 이동 조건·조사 결과: 공간 편차면 UNI, 종료시간이면 EPD, 관련 센서면 해당 OCAP으로 이동하고 최종 판정과 미확인을 기록합니다.

## 5. Terminator

- 조사 종결: 계측 신뢰성, 영향 범위, 원인 후보와 후속 조치가 기록됨
- 장비 복귀: etch rate와 관련 품질 지표가 승인 기준 안이고 SOP-ETCH-01 §4.8 재인증을 통과함
- Lot 처분: SOP-ETCH-20에 따라 별도로 승인함

## 6. 에스컬레이션

계측 원본이 없거나 후보를 구분할 수 없으면 공정 계측 담당과 설비 담당에게 올립니다. 제품 스펙 이탈 또는 반복 재발은 품질 담당과 SOP-ETCH-12 §4.9로 올립니다.
